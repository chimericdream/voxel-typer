# M4-03 Mobs, wave 1 (8 creatures)

Status: done. Waiting for the visual and IP review.

The eight wave-1 mobs and the Meadow's decorative hen now exist as voxel models with their anims,
home biomes, word flavors, speed classes and kid-facing names. Nothing in the app uses them yet;
M4-04 does that.

## What changed

- `src/content/mobs/<id>.model.json` (9 files): the models, in contracts §8.4 form. Sizes are whole
  model pixels, +z is the front, and every part hangs from one root part.
- `src/content/mobs/<id>.ts` (8 files): one `MobDef` each: `{ id, nameKey, aboutKey, home,
  speedClass, flavor, model }`.
- `src/content/mobs/ambient-chicken.ts`: the hen, an `AmbientDef` (no word, no speed class).
- `src/content/mobs/types.ts`: `MobId`, `MobDef` (it extends M4-05's `DefenseMob`) and `AmbientDef`.
- `src/content/mobs/index.ts`: `MOBS`, `mobById(id)`, `mobsOf(biome)`, `rosterFor(biome)`,
  `ambientChicken`.
- `src/i18n/en/mobs.ts` (new namespace `mobs`, registered in `src/i18n/en/index.ts`): a name and a
  one-line description for each mob, and the hen's name.
- `tests/unit/content/mobs.test.ts` (70 tests): see Acceptance.
- `docs/handoffs/M4-03/*.png` (27 files, 720 KB): the review screenshots.

Three things to know about the counts:

- **Cave Bat's words are capitalised.** Every item in the `theme=mines` lists starts with a capital,
  because the Deep Mines teach Shift. With lowercase keys only the count is 0, and the bat carries
  lesson words. It lives in the Mines, so a learner who meets it has Shift.
- **Slimeling in the Meadow carries lesson words.** The food words need letters the Meadow hasn't
  taught, so the director's fallback applies there. That is the designed behaviour.
- **There is no `theme=cold` pool.** The card's example tag doesn't exist; the Frosty Peaks lists are
  tagged `theme=snow`, and Frost Pup uses that. No pool was missing and no word was added.

Draw calls: one per part per mob type (measured in the Model Lab: each model adds exactly its part
count), doubled on High with shadows (decision 97). A night that shows every mob a biome can send
costs at most 76 calls, in Sky Citadel with all eight types.

## Decisions

- **Home biomes.** Two mobs live on the Sandy Shore (Cactus Cat, Sandstorm Imp), because the world
  has no desert biome. Sparkstone and Sky Citadel have no mob of their own in wave 1.
- **`rosterFor(biome)` = the biome's own mobs plus the mobs of every earlier biome.** A night in the
  Meadow has only Slimelings, and later nights add the friends already met. It is never empty.
  M4-04 can ignore it and filter `MOBS` itself.
- **`MobDef.model` is the raw JSON, typed `unknown`.** `src/content/` is a pure zone, so it can't
  import `parseModel` from `src/render/models/`. The consumer calls `parseModel(mob.model, mob.id)`.
  The unit test parses every model the same way.
- **One shared `hit` and `defeat` shape for every mob.** `hit` is a 240 ms squash. `defeat` is
  420 ms: the root grows to 1.2, then shrinks to nothing while it rises 4 px. Neither has a
  rotation or a flash. The sparkles and the block drop are M4-04's particles.
- **Flyers hover in the model.** Cave Bat and Lantern Fish have their root 5–7 px above y = 0, so
  M4-04 places every mob on the ground the same way.
- **Sandstorm Imp's tiers spin a quarter turn per loop.** A square part looks the same after 90°,
  so the loop has no jump and the first frame (reduced motion) is the rest pose.
- **Tiles are used where they help:** `mossy-cobble` and `grass` on the golem, `sand` on the imp.
  The other colours come from the M1-14 palette ramps. I tried the `lantern` tile on the fish, but
  at 3 px only the grey frame showed, so the lantern is flat amber.
- **The hen has `idle`, `walk` and `peck`, and no `hit` or `defeat`.** It is scenery.
- **`SIM_MOBS` stays as it is.** I tried the real roster in `tools/sim-defense.ts`. The acceptance
  test still passes, but every number in the `docs/sim.md` tables moves a little (for example
  50 WPM Sprout range 91.8–95.0 % against 91–95 %), and those tables are M4-05's evidence. The
  orchestrator can swap in `MOBS` from `src/content/mobs` (one line) when it reruns the report.
