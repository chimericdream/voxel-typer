## Decisions

- **`rollLoot` ctx gains `oreVein: boolean` (required).** The contracts' provisional-types table lets M2-04 "add whatever `rollLoot`'s ctx needs for 'epic only on ore-vein bonus'" and update every user. The only user was the pinned key list in `tests/unit/contracts/types.test-d.ts`, so I changed that one line. I made the field required so Mine mode has to decide it each time.
- **How odds work.** Streak, accuracy and band unlock a level (0–3). Each level has fixed tier odds: `[1,0,0,0]`, `[.65,.35,0,0]`, `[.45,.35,.2,0]` and `[.2,.3,.25,.25]` for common/uncommon/rare/epic. Each row dominates the one before, so rarity is monotone in streak by construction, and a single `rng.next()` picks the tier (inverse CDF). I chose these numbers for feel; M2-13's feel review can tune them in `TIER_ODDS`.
- **Accuracy 1.0 unlocks only `uncommon`**, as the card says. Thresholds are in `LOOT_THRESHOLDS`, per band: uncommon 10, rare 25 (Sprout 15), epic 40 (Sprout 25, and only on an ore vein).
- **An ore-vein bonus drops a second item** (PLAN §3.3: "ore veins give bonus items"). Both drops use the same odds. If both rolls land on the same block, they merge into one drop with the counts added. Each drop's count is `1 + floor(wordLen / 4)`.
- **Missing tiers fall back down.** If a table has no entries for the rolled tier, `rollLoot` uses the nearest lower tier that has entries. A table with no `common` entries throws, and so does a table for another biome than `ctx.biome`. These are content bugs, and the tests catch them.
- **Blocks outside the obvious file.** M2-04 owns only terrain, wood, stone, ores and flora. So brick and glass are in `stone.ts` (stone range), the lantern is in `ores.ts` with a deco/light num (300), and the wools are in `flora.ts` with wool-range nums (250–253). The test checks each file against its allowed ranges. Nums are what get saved, so a later move to `deco.ts` or `wool.ts` is free as long as each num stays the same.
- **Water was added** (not on the card's list) because M2-03 needs water blocks for the pond and owns no block file. It is tagged `terrain`, `transparent` and `liquid`, and it is not loot.
- **Names.** Every name is original and plain. The card's "meadowstone" gem ore is typed `gem`. Coarse dirt is "Rocky Dirt" (`rocky`). The flowers got made-up names to stay away from flower block names used elsewhere. Wool is typed by its color word.
- **Rarity of each block** (the table above): ground and trees are common; clay, mossy cobble, brick, char rock, flowers and wool are uncommon; copper, glass and the lantern are rare; meadowstone is epic.
