# M4-09 Inventory and loot screens

Status: done (screenshot baselines are made on CI by the Update snapshots workflow)

**My Blocks** is a new screen, opened from a new corner button on the World Map. It shows every
block the player has, with its count and a frame for how rare it is. A block that was found but is
all on the island still shows, with 0 and the note "They are all on your island!". A block not found
yet shows as a "?" on its dark silhouette, which is the collection goal. A panel beside the grid
gives the chosen block's name, how many the player has, how rare it is and where to find it. Two
filters, Island and Kind, narrow the grid. Every block has a little isometric cube icon, drawn once
on the app's one shared renderer.

## What changed

- `src/ui/screens/Inventory.tsx` + `Inventory.module.css` (new): the screen.
  - **Grid:** a `listbox` of `option`s with a roving tabindex, so the grid is one Tab stop and the
    screen opens focused on its first slot. The arrows move by slot (in reading order, stopping at
    the ends) and by row. Down into a short last row goes to the last slot. Home and End go to the
    ends, and PageUp and PageDown move a screenful within the column. The grid handles these keys
    in `onKeyDown` and calls `preventDefault`, so `useScreenInput` drops the same arrows when they
    arrive as controls (the M2-11 Tabs pattern). The screen's `onInput` handler only brings focus
    back to the grid when nothing has focus. Key repeats are swallowed. Choosing follows focus,
    so Enter is never needed. Escape goes back (the shell's default).
  - **Slots:** each slot has the icon, 1 to 4 rarity pips (so rarity never rests on colour) and,
    for rare and super rare blocks, an inner ring in the accent colour (a double ring for super
    rare). Found blocks have a count badge, 0 included. The badge text is drawn by CSS from
    `data-count`, so a screen reader's "Oak Planks, 1250" doesn't clash with a visible "999+"
    (axe `label-content-name-mismatch`). The chosen slot gets the kit's selected outline and
    corner notch.
  - **Details panel:** name (or "Not found yet"), "You have N." / the island note / "You have not
    found this one yet.", how rare ("Easy / Fun / Rare / Super rare find"), and "Found in
    lessons." (or "Look for it in lessons." for an unknown block). A block tagged with an island
    (`biome:`) also says "It comes from Meadow Home." (review of #205). The panel scrolls, with a fade, and becomes
    focusable only when its words don't fit.
  - **Filters:** two native `<select>`s (Island, Kind) in one row. A select is compact enough to
    fit at text scale 2 on 1024×600, which a row of chips was not. They list only the islands and
    kinds that have a slot. A change keeps focus on the select and announces "N blocks here" through
    the kit's one page live region (outside `#app`).
  - **Overflow:** the My Badges pattern (M3-FIX-8). The page is as tall as the window. The grid
    scrolls inside the room left over, its cut edge fades, and "More blocks below ↓" shows under it
    (pointer and screen reader only; out of the Tab order). Slot width is `4.5rem × --text-scale`,
    so columns scale with text size. A short window (`max-height: 640px`) uses a smaller title,
    tighter gaps, and puts the cue beside Back. The count sits beside the title, which leaves a
    whole row of slots, the panel, the cue and Back on screen at 1024×600 and text scale 2. A
    window under 640 px wide puts the panel under the grid. The cue's hop uses `--motion-ok`, and
    "More" scrolls instantly under reduced motion.
- `src/ui/screens/inventory-logic.ts` (new, DOM-free): `inventoryEntries` (owned / placed /
  unknown, using `foundBlocks(profile)`), `kindOf`, `filterEntries`, `filterChoices`,
  `collectionCount`, `gridMove`, `columnsFromTops`.
- `src/ui/components/BlockIcon.tsx` + `BlockIcon.module.css` (new): the icon component.
  `requestBlockIcon(app, def)` draws the cube once per block id and caches the data URI for the
  session. A failure is not cached, so a later mount tries again. It loads `@/render/block-icon`
  on demand, so three.js stays out of the screen chunk. Without WebGL, and while the cube is on
  its way, it shows the flat side tile (`blockIconUri` from `BadgeIcon`). Flowers (`sprig`) are
  always flat. `unknown` shows the image as a dark silhouette (`brightness(0)`, 30 %) with a "?".
  It calls `app.whenReady` so `__vt.ready()` waits for the icons.
- `src/render/block-icon.ts` (new; not in the card's Owns, but `BlockIcon.tsx` needs the three.js
  part in its own lazy module): builds an icon atlas once (`buildAtlas(blocks, BASE_PALETTE, 1)`,
  the world's default seed, so tiles match the world). It maps each `BoxGeometry` face's UVs into
  that face's atlas tile and draws an orthographic isometric view from (1, 1, 1), lit one light per
  axis (top 1, front 0.82, right 0.64). The draw goes into an off-screen target of the shared
  renderer, 3× supersampled. It reuses `SUPERSAMPLE` and `downsampleToSrgb` from `avatar.ts` and
  puts back the render target, clear colour/alpha and `autoClear` in a `finally`.

## Decisions

- **Which blocks show as "?":** only blocks some loot table gives. A block no lesson gives (water,
  the birch log) would be a "?" that can never be found, so it shows only once the player has it.
  The count reads "N of M blocks found" over those blocks (26 today).
- **Placed, never lost:** found (by `foundBlocks`) with 0 owned shows as a slot with "0" and "They
  are all on your island!".
- **Kinds** come from tags: flower, wool, light, ore, wood, terrain → Ground; anything else
  (cobble, brick, glass) → "Stone and glass".
- **Rarity words:** Easy to find / Fun to find / Rare find / Super rare find, with 1–4 pips. They
  name how often it turns up. Nothing says "hard" or asks for speed.
- **Native selects for the filters:** they fit at text scale 2 on 1024×600, and they are
  keyboard and screen-reader complete. Their arrows belong to them, so the screen handler leaves
  arrows alone unless nothing has focus.
- **Icons use a base-palette atlas** with the world's default seed, not the scene's live atlas,
  whose palette follows the current island. That way an icon looks the same wherever it is first
  drawn, and one cache serves the whole session.
- **No Builder entry:** Builder is a play mode with its own HUD and pause menu. A button there
  means changing mode code this card doesn't own, and the map's corner is one Escape away. See
  Questions.

## Review fixes (orchestrator review of #205)

- **Counts under the rarity rings:** the rare and super-rare rings (`.slot::after`) were drawn
  over the count badge, so "3", "0" and "2" on glass, the ores, the gem block and the lantern were
  hard to read. The badge and the pips now have `z-index: 1`, above the ring. The rich e2e checks
  the order, and I looked at the slots at 1280×720, at 1024×600 with scale 2, and in high
  contrast.
- **Honest "where":** lessons on every island roll from the Meadow table, so the panel now says
  "Found in lessons." / "Look for it in lessons.". Only a block with a `biome:` tag names an
  island ("It comes from Meadow Home."), and the Island filter now uses those tags only.
