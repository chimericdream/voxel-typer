## Decisions

- **The parent gate is a speed bump, not security** (for `docs/decisions.md`).
  - It stops a young child from wandering into delete or band changes by pressing keys.
  - Anyone who can read a Builder word can pass it, and nothing is secret or stored.
  - Real protection (a PIN or a grown-up account) would need data a family must remember or keep
    on the device. That is out of scope for v1 (PLAN §6.7).
- **The gate word** is a random 6–8 letter word from the shipped `birch-builder` and
  `shore-builder` lists. The word-list validator already checks those for safety, which leaves
  about 390 words.
  - It is picked through `Rng.pick` from a `createRng(seed)` stream. The seed comes from
    `crypto.getRandomValues`, in UI code, never `Math.random()`.
  - Tests inject `rng` and `words`.
  - It is shown as plain text and compared without case or edge spaces.
- **3 wrong tries start a 30 s rest.** The count lives in one app-wide tracker, so "Not now" and
  coming back doesn't reset it, but a reload does. After the rest there is a new word.
  - While resting, the field is disabled, with "Let's take a short break. Try again in N seconds."
  - The copy addresses grown-ups and stays kind: "That's not quite it. 2 more tries."
- **One gate per Settings visit.** Passing it opens the Grown-ups tab until you leave the screen.
  Each danger action then asks for a confirm in a kit `Dialog`. On Profiles, M3-09 asks for the
  gate on every action, as before.
- **The gate renders inline,** never as its own `<dialog>`. It sits in a tab panel or inside
  Profiles' change dialog, so that dialog's focus trap still holds. Its field carries
  `data-autofocus`, and it also focuses itself on mount.
- **Keyboard:**
  - Up/Down step through the selected tab, then every control, then Back.
  - Arrows inside a slider, a radio group or a text field belong to that control.
  - Left/Right on the tabs are the kit's own keys, and the router sees `keyAlreadyHandled`
    (M2-11).
  - Escape goes back to the map.
- **The band change reuses M3-09's `withBand`.** Band defaults follow the new band only where the
  grown-up hadn't changed them. Delete uses `app.removeProfile`, which also removes `:prev` and
  refuses newer-build saves.
- **"Picture: auto" means medium** until M6 measures the device.
