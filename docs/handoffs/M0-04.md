# M0-04 Hello voxel

Status: done (screenshot baseline pending the Update snapshots run, see below)

## What changed

- `src/dev/hello-voxel.ts`: a cube with a seeded 16×16 two-tone noise texture (`DataTexture`, `NearestFilter` for min and mag, `generateMipmaps = false`, sRGB) on a sky-blue (`#87ceeb`) background. Six `MeshBasicMaterial`s with different grey tints give the faces their shading without lights. Inline mulberry32 PRNG. `?seed=<n>` seeds the texture (random seed when absent). `?freeze=1` renders one frame at a fixed pose and stops the loop. `#app` gets `data-ready="1"` one frame after the first render.
- `src/main.ts`: calls `startHelloVoxel(#app, location.search)`.
- `tests/e2e/hello-voxel.spec.ts`: loads `/?freeze=1&seed=1`, waits for `data-ready`, reads the canvas pixels, checks them (below), then `toHaveScreenshot("hello-voxel.png")`.
- `tests/e2e/__screenshots__/hello-voxel.spec.ts/hello-voxel.png`: committed by the Update snapshots workflow.

## Acceptance

- [x] Screenshot test at `?freeze=1&seed=1` passes; pixels show hard texel edges (no blur).
  - Pixel check (runs locally too, it is not a snapshot comparison): the renderer uses `antialias: false` and `preserveDrawingBuffer: true`, and the test copies the WebGL canvas to a 2D canvas and reads every pixel. It asserts: background is `#87ceeb` (±5); the cube covers >10% of the frame; the cube has ≤ 12 distinct colors (2 tones × 3 visible faces); for every pair of horizontally or vertically neighboring cube pixels, >85% are identical (max channel diff ≤ 2), >1000 are sharp texel edges (diff ≥ 24), and <1% are in between (those are the lines where two faces meet).
  - Local SwiftShader run: `cubePixels 181480, distinctCubeColors 6, equalPairs 344966, sharpPairs 16421, softPairs 541`.
  - Mutation check: with `magFilter = LinearFilter` the test fails (`distinctCubeColors` 541, `softPairs` 152483).
- `npm run verify` passes locally. `npm run e2e` passes locally (2 tests; screenshot comparison skipped outside CI as configured).

## Decisions

- Texture from a `DataTexture` rather than an `OffscreenCanvas`: smallest code for a throwaway demo; M2's atlas does the real thing.
- No lights: per-face tinted `MeshBasicMaterial`s keep every face to exactly two colors, which keeps the pixel check exact and the render deterministic.
- `setPixelRatio(1)` so the canvas pixel grid matches the screenshot.
