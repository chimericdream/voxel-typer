## Decisions

- **The laptop is the main path, Proxmox comes later.** The owner says nothing is deployed yet,
  so the script mentions `deploy/README.md` only as "later, once the home server exists". The
  card's Spec puts Proxmox first, which no longer matches the facts.
- **Reading fps, two ways.** The browser's own meter (DevTools → Rendering → Frame rendering
  stats) works on the normal build. `__vt.fps()` is the game's rolling live-play average. It is
  left out of the production build (`src/main.ts` installs it only when `MODE !== "production"`),
  so the script uses the test build for it: `npm run build:test`, then
  `npx vite preview --mode test`, which serves `dist-test/` on the same port.
- **Privacy in the notes:** the template asks for initials only and says no photos or recordings.
  Child safety and privacy come first.
- **Commands work in both shells.** Each step is one command with no `&&`, so the same text works
  in PowerShell 5.1 (which has no `&&`) and in Git Bash.
