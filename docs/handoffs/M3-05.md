# M3-05 Placement test mode

Status: done

A new player now gets "Find your level" straight after making their player. It is a 90-second Mine
run whose blocks climb a ladder of key sets. Its result picks the start biome, unlocks the islands
up to it, and gives the lessons before it one star each ("tested out"). A clear **Skip** (or
Escape) starts at Meadow Home and changes nothing.

## Placement rules and thresholds (for the pedagogy review)

**The ladder.** The test starts on the home row. A rung opens when 8 of the last 10 blocks on the
current rung broke with no slip; the count starts over on the new rung. When a rung opens, the
blocks left over from the old rung are dropped, so the very next block is from the new rung.

| Rung     | Blocks show                                      | Keys                            | Start biome if the test stops here |
| -------- | ------------------------------------------------ | ------------------------------- | ---------------------------------- |
| home     | single letters                                   | `a s d f g h j k l ;`           | Meadow Home                        |
| top      | single letters, new keys weighted up             | + `q w e r t y u i o p`         | Birch Forest                       |
| bottom   | single letters, new keys weighted up             | + `z x c v b n m` (not `, . /`) | Sandy Shore                        |
| words    | words from `frosty-<band>`, up to 7 letters      | a–z                             | Frosty Peaks                       |
| capitals | words from `mines-<band>` (names with a capital) | a–z, A–Z                        | Deep Mines                         |
| numbers  | single digits                                    | `0–9` only                      | Mushroom Marsh                     |

Sprouts stop at the words rung, so a Sprout never starts past Frosty Peaks. Nobody starts past
Mushroom Marsh.

**The estimate.** The start is the furthest biome on that path for which all of these hold:

1. the test reached the biome's rung;
2. net WPM and accuracy over the whole test meet the biome's gate and every earlier gate;
3. the band allows it (Sprout: Frosty at most).

| Start          | Net WPM ≥ | Accuracy ≥ |
| -------------- | --------: | ---------: |
| Birch Forest   |        12 |       88 % |
| Sandy Shore    |        17 |       90 % |
| Frosty Peaks   |        26 |       92 % |
| Deep Mines     |        32 |       93 % |
| Mushroom Marsh |        38 |       94 % |

A test with under 30 s of active typing (`PLACEMENT_MIN_ACTIVE_MS`) starts at the Meadow. Net WPM
counts a single letter as one char, as everywhere in the game. Every wrong-key policy is `stay`
for the test, so a slip never moves the cursor on.

**Other rules.**

- Calm mode has no timers anywhere, so there the test ends after 60 blocks
  (`PLACEMENT_CALM_BLOCKS`) instead of 90 s.
- No countdown for any band. The progress bar fills with time instead.
- The test's session counts like any other (session counter, bigram stats, history with mode
  `placement`, loot). `baselineNetWpm` ignores `placement`, so it doesn't change stars.
- Key stats: the test's per-key baseline (`keyBaseline`) fills in keys the profile has no stats
  for yet. Stats from real lessons win.

The sim can't show that; the M3-GATE child playtest can.

## Decisions

- **"Tested out" is stored with no new field:** `{ bestStars: 1, bestNetWpm: 0, bestAccuracy: 0,
  plays: 0, lastPlayed: <test time> }`. A real play always has `plays ≥ 1`, so `plays === 0`
  means tested out (`isTestedOut`). The map already counts the record as played, so the next lesson
  opens and the node shows one star. Nothing in the frozen `Profile` changes.
- **When a biome has no lessons yet:** the start is `playableStart(estimate)`, the furthest biome
  at or before the estimate that has lessons. Only the lessons before _that_ biome are tested out,
  so the player always has a new lesson to play. Today only Meadow has lessons, so every result
  starts at the Meadow and tests nothing out. The outcome screen then says "You are ready for
  {estimate}! Its lessons are coming soon, so you start at Meadow Home." When more biomes ship,
  the same rule places players further with no code change. `progress.placement.startBiome` stores
  the start actually used, not the raw estimate.
- **The placement result has `stars: 0`.** The test has no pass mark. `extra.placementTier` carries
  the highest rung reached, and the estimate is made from it when the result is applied (in the
  play host, not in the mode), so the mode needs no lesson list.
- **No countdown and `stay` for every band:** this is a child's first minute in the game, so there
  is no race against a clock and no skipping past a slip.
- **Only on first launch.** A player who skips, or quits from Pause, starts at the Meadow and isn't
  asked again. Retaking the test is for a later card (Settings → Grown-ups?).
- **The test's lesson id is `"placement"`.** It doesn't follow the `<biome>-<nn>` pattern on
  purpose, and it never goes into `progress.lessons`.
- The bottom rung leaves out `, . /`. They come with the punctuation lessons, so a player isn't
  marked down for keys the Meadow-to-Shore path never asks for.

## Notes for downstream tasks

- **M3-11 (Parent Dashboard):** a lesson record with `plays === 0` was tested out by the placement
  test. Its `bestNetWpm` and `bestAccuracy` are 0 because nothing was measured, so never show them
  as a score. Placement sessions are in `history` with `mode: "placement"`.
- **M3-06 (`recommendNext`):** tested-out lessons count as played with 1 star. The map's current
  "lowest stars" fallback will point at them once everything is played. That is fine, but you may
  want to skip `plays === 0` records there.
- **M3-14:** the keyboard flow is new player → placement (Tab, then Enter on Skip; or Enter on
  "Let's dig!") → map.
- **Mine hooks:** any later Mine-based mode can use `MineOptions` the same way. Without `opts`,
  Mine is unchanged.
- **More biomes:** placement picks them up automatically through `playableStart`. The word rungs
  use `frosty-<band>` and `mines-<band>`, which already ship.
