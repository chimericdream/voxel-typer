## Decisions

- **Single-letter targets use Atkinson Hyperlegible (`--font-body`), not Pixelify Sans.** At 24 px, Pixelify's `b`/`d` and `q`/`p` are exact pixel mirrors, `1` differs from `l` by one pixel, and the single-storey `a` is close to `d`/`q`. Atkinson separates all of these. Accessibility and learning come before visual style (`PLAN.md` §12.8). Pixelify stays for headings, HUD and buttons.
- **No subsetting.** OpenDyslexic has the Reserved Font Name "OpenDyslexic", so a subset would have to be renamed. Shipping the upstream WOFF2 files byte for byte avoids that. The other two are about 23 KB per face, and browsers only fetch a face when text uses it, so OpenDyslexic costs nothing until the toggle is on.
- **Pixelify Sans uses the upstream variable WOFF2** (one 23 KB file for 400–700) instead of separate Regular and Bold files (26 + 27 KB). The file was renamed from `PixelifySans[wght].woff2` to `PixelifySans-wght.woff2` to avoid brackets in URLs; its bytes are unchanged.
- **No italics.** The UI kit uses none. Atkinson Italic and OpenDyslexic Italic can be added later from the same commits.
- **Font sources for `docs/decisions.md`** (`README.md` §8.9 asks for this; the orchestrator owns that file): Pixelify Sans from `github.com/eifetx/Pixelify-Sans@39df74a`, Atkinson Hyperlegible 1.393 from `github.com/googlefonts/atkinson-hyperlegible@1cb3116`, OpenDyslexic from `github.com/antijingoist/opendyslexic@1824da5`. All SIL OFL 1.1.
- **Outside Owns:** the one-line import in `src/main.ts` (M2-10 owns it; it should keep the line, next to the `tokens.css` import M2-07 asks for), the preload `<link>` in `index.html`, and `tests/e2e/fonts.spec.ts`.
