## Decisions

- **Flow 3 measures one run, not two.** The first draft compared a straight play with a paused play of the same lesson. On this loaded machine the same keys took 41 s in one run and 59 s in the next, which is more than the pause, so the comparison was noise. One run with the wall time measured around the pause pins the same property: paused time is not active time, so the summary WPM is the typing's WPM.
- **Profiles focus:** the first player already has focus when Profiles opens after the splash key, so one Enter picks it. The test asserts the focus and then presses Enter.
- **Results screenshot uses a fresh Sprout** (no history, no WPM-relative star), so the stars and message don't depend on real-time typing speed. Loot depends only on streak and seed.
- **Baselines settle by frames, not wall time.** The break's chips and loot flight run on frozen frame time (about 75 frames). The first Update snapshots run waited 1.2 s of wall time, and on CI's slow SwiftShader `mid-word` never got two equal frames. `settle()` now waits 150 animation frames, and the two in-play shots get a 30 s screenshot timeout.
- **Mid-word uses meadow-05's first word** ("ad" at seed 1), typed halfway.
- **Perf is soft.** FPS is logged only. Draw calls are an `expect.soft` in flow 2 (the hard ≤ 150 check stays in `mine.spec.ts`). Peak draw calls were 25–26 in every lesson; FPS on local SwiftShader was about 30–42.
- **Kid speeds:** Sprout 12–20 WPM, Miner 30–45 WPM, 3–8 % slips. A full 1–6 run is about 6 minutes on a loaded machine (CI has 3 shards and 30 minutes).
