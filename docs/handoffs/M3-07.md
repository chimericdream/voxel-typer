### Reduced motion covers

- **Camera:** drift (play only) and shake (`camera.ts`); glides and `moveTo` snap instead.
- **Scene:** hit-stop (`scene.ts`), water wobble (`waterMotion && !reducedMotion`), cloud drift
  and the sun's glide (`sky.ts`).
- **Mine:** the block's swing, wobble, slide and recoil (`modes/mine/view.ts`, via the shared flag
  now); float-text pop and squash (`fx/float-text.ts`).
- **UI CSS:** every kit, HUD, keyboard and screen animation multiplies its duration by
  `--motion-ok`. That covers the HUD bob, keyboard bob and wobble, dialog drop-in, toast pop,
  stars, Results slots, splash bob and Toggle slide. `motion.css` catches anything that forgot.
- **Map (M3-04):** the pulse and hop through `--motion-ok`; lift and camera moves through
  `prefersReducedMotion`, which now uses the shared flag.
- **Locked-island wobble (M3-FIX-1):** not in my files. Use `prefersReducedMotion(setting)` from
  `nav.ts` or `reducedMotion()` from `@/a11y/motion` in JS, and `--motion-ok` in CSS. Both are the
  same flag.
- `?freeze` hooks are kept as they were (`frozen`, `waterMotion: !frozen`, sky `frozen`).

### Flash guard

- **Rule:** at most 3 flashes start in any 1000 ms (sliding window). Refused flashes don't count.
  If the clock runs backwards, the guard resets.
- **Wired:** the on-screen keyboard's wrong-key outline. It already had a 600 ms gate; the global
  guard now has the last word, so two effects together still can't pass 3 a second.
- **Tests:** unit tests use an injected clock and a fast-check property (seed 307) that no
  one-second window ever holds more than 3. A DOM test checks that a wobble is refused after 3
  page flashes and allowed 1 s later.

### Manual screen-reader checklist (for the owner or the reviewer; NVDA + Chrome or Narrator + Edge)

1. Splash: "Press any key to start" is read. Tab reaches "How we keep you safe", and it is read
   as a button.
2. Press a key. "New player" (or "Who is playing?") is announced once.
3. New player: the name field is read with its label, "Type a name for your player". The hint
   and the letter count are read. Each group button and skin choice has a name.
4. World map: "World Map" is announced. Each island button reads its name and state. The arrow
   keys move between islands; Enter opens an island; each lesson reads "Lesson N: title…".
5. Lesson intro: "Next lesson: …" is announced, and focus is on "Start".
6. In play, nothing is announced per keystroke. The word is read as "Type: …" when you go to it.
   Caps Lock on reads "Caps Lock is on! Tap it to turn it off." A wrong key reads "Almost! Try
   that key again" at most once every 5 s.
7. Results: "Lesson done! N stars out of 3. <message>" is announced, then the focused button
   ("Next lesson").
8. Escape on the map: "Who is playing?" is announced.
9. A save toast (if one shows) is read once, and its "OK" button has a name.
10. With Windows Contrast themes on, focus rings, buttons and the next key stay visible.

## Decisions

- **Font setting meaning.** `pixel` (default) keeps Pixelify on headings and chrome. `clean`
  points `--font-pixel` at the body font, so there is no pixel font anywhere. `dyslexic` uses
  OpenDyslexic everywhere, typing targets included. Otherwise `pixel` and `clean` would look the
  same, because body text is already Atkinson (decision 68). `--font-body` is never Pixelify.
- **One motion flag.** The OS preference is watched live, not read once. `main.ts` used to cache a
  boolean at settings-apply time, so `'system'` missed OS changes mid-game.
- **The hear-again hint is new UI.** No visible affordance existed before. It shows the key (`` ` ``
  for Sprout, `F1` for others) when `tts` is on and a local voice exists. CI's headless Linux
  Chromium has no local voices, so the hint never shows there and HUD baselines don't change.
- **Route announcements skip play and the first screen.** The page is read on load anyway.
  Unbuilt routes announce "Coming soon!", matching what they show.
- **The held-Enter guard is page-wide** (capture phase), not per control, so later controls are
  covered without remembering to add it.
- **`__vt.camera()`** joins `drawCalls()` as a dev/test-only extra; the production build drops it.
