## Decisions

- **Wrong-key `seq` travels in `HudState.custom.wrongKey`, not the events bus.** Modes already hold the bridge. The bus is per lesson and the HUD can't see it. A mode calls `reportWrongKey(ctx.hud, e.got)` for every engine `wrong` event, repeats included: M2-09's `feedWobble` gates repeats and rate. `HudKeyboard` reads the slice through a computed, so other `custom` slices don't re-render the keyboard.
- **Marks.**
  - `pending` is the full ink.
  - `ok` steps back to the muted ink ("typed chars darken", read as "step back").
  - `fixed` is muted with a dotted underline.
  - `wrong` is a wavy underline plus a diagonal hatch in a shade of the text color, never red.
  - In the high-contrast theme `text` and `textMuted` are both white, so typed and pending chars differ only by position against the cursor.
- **No flashing.** No mark animates. A mark changes only on a key press, and a held key keeps the same mark, so key-repeat can't make anything flash. The keyboard wobble keeps M2-09's gate (under 2 a second).
- **Cursor.** A thick bar under the next char and a soft tint behind it, always. With motion on, a gentle 1.4 s bob (`translate`, multiplied by `--motion-ok`), so under reduced motion only the bar and tint stay.
- **Fonts.** All target text (single letters, short and long words) uses `--font-body` (Atkinson), per M2-08. The pixel font is only for the timer and the kit's toasts.
- **One message at a time; the Caps Lock hint wins over the banner.** At text scale 2 on a 720-px screen the stage between the word and the keyboard holds one toast. While Caps Lock is on the child can't type the word, so the hint matters more. The banner shows again once Caps Lock is off.
- **Fit at text scale 2.**
  - The keyboard area is capped at 54 % of the viewport height, and a `size` container sets `--keyboard-max-unit` from that height (8.1 key units with hands, 5 without).
  - So at 720 px tall, keys are about 43 px at every scale ≥ 1.1. Text scale is a letter-size setting, and the word grows with it: 72 px at 1.5, 86 px at 2 (capped at 12 % of the viewport height).
  - On 1080-px screens the keys grow to 67 px.
  - The combo slots stop at 64 px. They show the streak, not text.
  - Toasts in the HUD are capped at `min(20px × scale, 3.6dvh)` and stay on one line.
- **Finger labels on every key for Sprout** (M2-09 N3), because a keyboard-only child never hovers.
- **The timer re-renders only when its `m:ss` text changes**, so a mode can send `remainingMs` every frame.
- **The HUD takes no pointer input and never takes focus.**
