## Lengths per band

Each cell is the chars budget / the keys a child actually types (mean over 50 seeds, Sprout
0.6 / Miner 1 / Builder 1.3). Mine breaks a word block on its last letter and ignores a habit
space (decisions 81 and 90), so words lessons type about 15 % fewer keys than their budget. To
make up for the dropped spaces, the M3-03 lessons get bigger budgets than Meadow 1–6 (Miner 60–95
chars, against 50–60). The same
tables sit at the top of each lesson file.

| Biome  | Sprout keys | Miner keys | Builder keys | Mastery          |
| ------ | ----------- | ---------- | ------------ | ---------------- |
| Meadow | 25–45       | 41–70      | 53–90        | 90 s, every band |
| Birch  | 36–52       | 48–84      | 63–111       | 90 s, every band |
| Shore  | 39–56       | 65–89      | 85–116       | 90 s, every band |
| Frosty | 42–56       | 70–93      | 91–124       | 90 s, every band |

Lengths grow slowly through the biomes. At Sprout's estimated 6 WPM (about 30 keys a minute), the
longest Sprout lesson is just under 2 minutes. The mastery checks have `bandScale` 1 for every
band, so "90 s" means 90 s for a Sprout too, not 54 s. In calm mode that becomes about 45 chars
at the child's own speed. Drill lessons (Birch 03, 06, 09, 11; Shore 01, 03, 06, 09) give Sprouts
0.75 instead of 0.6, so each new key turns up in almost every session (next section).

## How drills, reviews, challenges and mastery work

- **Drills.** The card's pattern per pair is letters → syllables → words. With 14–27 keys allowed,
  syllables bury a consonant pair. I measured the share over 200 seeds (focus weight 3 against 2,
  contracts §4):
  - As syllables, `t y` got 9 %, `q p` 8 % and `n b` / `c x` 6 %. A Sprout session was missing a
    new key 42–66 % of the time.
  - As letters, they get 11–17 %, and a session misses a new key 4–13 % of the time.
  - Pairs with a vowel do fine as syllables (`r u` 24 %).

  So every drill is single letters except Birch 03 (`r u`, syllables). Each pair then gets a
  words lesson. There's room for two lessons per pair, not three: 5 pairs + 3 reviews + challenge
  - mastery + boss = 15. `biomes-1-4.test.ts` requires each new key ≥ 2 times per Sprout session
    on average, and in ≥ 85 % of sessions.

- **Reviews** (every 4th lesson: Meadow 08 and 12; Birch and Shore 04, 08 and 12; Frosty 04 and 08)
  have `newKeys: []`, so every allowed key weighs the same, and the word reviews mix in the
  earlier biomes' pools. The kinds vary: Meadow syllables + words; Birch letters + words + phrases;
  Shore words + phrases + phrases; Frosty letters + words. A phrase review is the biome's space-bar
  practice where it has one. Meadow 04 came before the rule, so it stays a new-key lesson.
- **`j` and `;`** (M2-12 review N2): every drill and letters review allows them, so each comes up
  1.5–3 times per Sprout session in Meadow 07, 08 and 11, in every Birch and Shore drill and in
  Frosty 04. No real word has `;`, so word lessons can't practise it. Tested per biome.
- **Challenge** (`challenge-hide-keyboard`, one per biome): Meadow 11 (letters, the classic
  "don't look down" drill), Birch 13, Shore 11 and Frosty 07 (words). No speed target. **Nothing
  acts on the tag yet** (no hidden keyboard, no cosmetic; see Notes).
- **Mastery:** 90 s for every band, a `phrases` lesson over word + phrase pools, so the targets mix
  single words and short phrases. Accuracy target 0.9. **With the band table (decision 80), 0.9
  sets the same bars as 0.85 in every band:** Sprout max(0.85, 0.85) = 0.85, Miner max(0.88,
  0.88) = 0.88, Builder max(0.90, 0.90) = 0.90. So a Sprout unlocks the next biome at 85 %
  accuracy. To make mastery stricter than other lessons, the target would have to be above 0.90
  (for example 0.92 gives 0.87 / 0.90 / 0.92). I kept the card's 0.9.
- **Boss:** last in each biome, `mode: "boss"` + `tags: ["boss"]`, falling back to Mine (contracts
  §7.3). It doesn't gate the next biome; mastery does. Its pools are the biome's phrases, so it
  differs from the mastery check until M5's boss mode.
- **Speed (Frosty):** `wpmRelative` 1.0 → 1.05 → 1.1 → 1.15. It gates only the 3rd star, never
  for Sprouts. The letters review and the challenge have none. Sim, 50 runs, session 5 (the
  baseline needs 3 sessions):

  | Lesson            | avg Miner 2★ / 3★ | fast Builder 2★ / 3★ |
  | ----------------- | ----------------- | -------------------- |
  | frosty-01 (×1.0)  | 46 % / 54 %       | 48 % / 52 %          |
  | frosty-06 (×1.1)  | 88 % / 12 %       | 86 % / 14 %          |
  | frosty-10 (×1.15) | 98 % / 2 %        | 94 % / 6 %           |

  The sim's typists don't get faster, so ×1.15 means "beat your own median by 15 %". That is close
  to unreachable for a steady child, and that is the card's intent only if the 3rd star is meant to
  be rare. **Pedagogy question below.**

- **Mastery sim** (`tools/sim.ts`, 50 runs, S1 → S5 stars ≥ 2): slow Sprout 98 % → 98 %, avg
  Miner 100 % → 100 %, slow Builder 80 % → 84–90 %, fast Builder 100 %. The sim types words and
  phrases lessons as syllables (it ignores pools, M2-12 note), so this is approximate.

## Sprout phrases (why new lists)

The `space` rule needs a phrases lesson per biome, and `real-words` needs ≥ 70 % pool items in
every band. M3-02 wrote phrases for Miner and Builder only, so a Sprout in a Birch phrase lesson got
the syllable fallback. Each new Sprout list has 2–4 easy words from that biome's Sprout list, the
theme lists or Dolch. They contain no falling or fear readings, no drinking readings (checked
across word pairs) and no brands. Birch phrases use only Meadow and Birch keys (the validator
enforces this).

## Decisions

- Drills are letters, except Birch 03 (syllables), because syllables bury consonant pairs in large
  key sets (numbers above).
- Shore order `m v`, `n b`, `c x`, `z`: mirror pairs from the index fingers out, as in the Meadow.
- Mastery gets `bandScale` 1 in every band, so the card's 90 s holds for Sprouts too.
- Mastery and boss are `phrases` lessons. Mastery mixes word and phrase pools ("mixed content"),
  and the boss uses phrases only.
- No `wpmRelative` on letters reviews or challenges. Single-letter blocks are slower than words
  and would be judged against a words-heavy baseline.
- No sentences in biomes 1–4. Mine draws each target as one block, so a 40–70-char sentence
  doesn't fit. `frosty-sentences-*` wait for a flowing-text (practice) mode.
- Lessons name their pools explicitly. The default `biome=<id>` tag would mix phrase lists into
  words lessons.
- Theme lists (`band=all`) are in Birch, Shore and Frosty word lessons, for flavor (M3-02's intent).
- New Sprout phrase lists; `fad`, `fads` and `falls` kept; `beige` and `wren` out, `dove` in;
  theme tags fixed (reasons above).
- Titles avoid "phrases" and "mastery" (hard for a 6-year-old). The mastery check is "Show What
  You Know" in every biome.

## Notes for downstream tasks

- **The challenge tag has no behavior yet.** Something must hide the on-screen keyboard and hand
  out the card's cosmetic for `challenge-hide-keyboard`. That belongs to Mine (or M3-07/M3-10).
  The card calls the challenge "optional", but a lesson opens only when the one before it is
  finished. So the challenge must be completed (any stars) to move on. It sits one to four
  lessons before mastery. If it should be skippable, the map's unlock rule needs a change.
- **Mine ignores `reviewKeys`.** `keyWeights` gets `focus: lesson.newKeys` only (mine.ts, the
  validator and the sim all do the same). Contracts §6 says review keys are "emphasized", but today
  a review lesson weighs every key the same. I set `reviewKeys` to the keys each lesson is meant to
  bring back (the pair just learned, or the whole row), so a later fix works without data changes.
  See the Questions.
- **Defense sim is sensitive to the theme lists.** `tests/unit/sim/sim-defense.test.ts` ("per-wave
  median ≤ 0.965") failed at 0.967 for Miners after `wren` was removed. With `dove`, `bat` or `ram`
  in its place it passes, and with `mule` it fails. It is noise around a tight bound, and M4 should
  know that any theme-list edit can trip it.
- **M3-06 (`recommendNext`, remedial):** each biome's reviews are letters/syllables plus words plus
  phrases, so a remedial lesson only needs to add focus keys.
- **M5 (bosses):** `meadow-14`, `birch-15`, `shore-14` and `frosty-12` are the boss slots
  (Cobble Colossus, Bramble Stag, Tidecrab King, Frost Wyrm). Their titles live in i18n only.
- **Test harness:** `mount({ lessons })` lets screen tests pin a curriculum.

## Contract change request / Questions

- **Pedagogy question 1 (speed ramp):** keep ×1.15 on Frosty 10–12 (3rd star in about 2–6 % of a
  steady typist's sessions), or cap the ramp at ×1.1 (about 12 %)? It's one number per lesson.
- **Pedagogy question 2 (mastery bar):** the card's 0.9 sets the same star bars as 0.85 in every
  band (above). Is "Sprout unlocks at 85 %" the intent?
- **Question 3 (review emphasis, engine).** Mine could use `focus = newKeys.length ? newKeys :
  reviewKeys`, a one-line change in `mine.ts`, plus the validator's and the sim's `generateFor`.
  Then reviews would weight their `reviewKeys` (for example `j ;`), as contracts §6 describes.
  Without it, `reviewKeys` is documentation only. It is outside this card, so I didn't change it.
- **Question 4 (new-key share, engine).** The focus floor is a flat weight of 3 against 2, so a
  pair's share falls as the key set grows: 47 % in meadow-02, but 11–13 % in Shore's drills, and 5 %
  for `z`. A focus share floor in the generator or adaptive weights (for example "focus keys
  together get ≥ 30 % of chars in letters and syllables", inside the comfort cap's 50 %) would let
  drills stay short. That is M1-05/M1-06 tuning, not lesson data. Until then, the drills here run
  0.75 for Sprouts, so each new key still shows up 2–3+ times per session.
