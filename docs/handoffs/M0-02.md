## Decisions

- **The copy lint is a script, not an Oxlint JS plugin.** Oxlint 1.93's own config schema says "JS plugins are in alpha and not subject to semver".
- **More text props than the card lists.** Besides `title`, `aria-label`, `placeholder` and `alt`, the check covers `aria-description`, `aria-placeholder`, `aria-roledescription` and `aria-valuetext`, because screen readers read them to the player too.
- **"Allowed" means the text has no Unicode letter (`\p{L}`).** So numbers, punctuation, symbols, emoji and whitespace pass, and letters from any script fail. HTML entities are decoded first: numeric ones fully, plus a short list of named symbol entities (`nbsp`, `mdash`, `times`, …). Any other named entity, such as `&eacute;`, counts as letters, which is the safe side.
- **String literals as JSX children are flagged too** (`{"Hello"}`, ``{`Hi ${name}`}``, either branch of `?:`, either side of `&&`/`||`/`??`). Without this, `{"Hello"}` would be an easy way around the rule.
- **No suppression comment.** There is no way to silence the check for one line. Text that isn't kid-facing doesn't belong in JSX text or these props. If a real need shows up, add a `// ui-literal-ok: <reason>` escape in the tool then.
- **Only `src/ui/**` is scanned,** as the card says. `src/app/` and mode folders (`src/modes/**`) are not. See Questions.
