# M4-08 Blueprints, expansion, orbit, PNG snapshot

Status: done. Screenshot baselines are made on CI (see "Baselines").

A child who earns a badge gets a **plan**: typing its name on My Island stamps a small build.
Completing a biome after the Meadow makes the island **grow** by one ring. Typing **`photo`** saves a
picture of the island to the downloads.

To try it: `npm run dev`, then `/?profile=island-builder&screen=island&nosave=1`. This is a Miner
with the First Steps, Meadow and Birch badges and enough blocks for a house. The island grows one
ring, and the plans line says `well house tower`.

## Decisions

- **"Biome completed" means its badge `<biome>-master`,** which is every lesson of the biome played
  (M3-10). It sits in `profile.achievements`, which only grows, so neither a plan nor a ring can be
  lost. Biome blueprints and expansions use the same test (`biomeCompleted`).
  - A biome skipped through the placement test has no badge until its lessons are played.
- **Rings:** one for each of Birch, Shore, Frosty, Mines, Marsh and Caverns (decision 99). The
  Meadow's reward is the House.
  - The save keeps only a count, so the first N completed biomes are taken as given.
  - Every ring uses Meadow terrain today, so the order makes no visible difference yet.
- **The ceremony plays on the next My Island visit,** not at the end of the lesson. The island and
  its WebGL scene only exist in Builder, so the same one context is used.
  - The sweep is 1.6 s out (a quarter turn, high and wide), then 0.9 s per ring, then 1.6 s back.
  - Keys wait while it runs.
  - Pause or leave finishes it at once.
  - There is no flash, so `allowFlash()` is never needed. The cheer is grass bursts at the ring's
    corners plus the `star` sound.
  - An expansion counts as an edit for saving, so a fresh island with a ring is written. It is not
    an undo step.
- **`photo` is a typed command.** PLAN says commands are real words, and the word suits a Sprout.
  It is offered only when a 3D scene exists.
- **"2×"** means twice the canvas's CSS size. The longest side is capped at 4096 and at the GPU's
  `maxTextureSize`.
  - The picture is copied by `toBlob` in the same task as the draw, so `preserveDrawingBuffer` is
    not needed.
  - The DOM HUD is never in the picture, because it comes from the WebGL canvas. Only the 3D cursor
    and ghost are hidden.
  - The Blob URL is revoked 10 s later.
- **Bridge is typed `arch`.** `bridge` would turn the Sprout code for brick from `bri` into `bric`,
  which changes an existing Builder word (the owner's Sprout-words question is still open). The
  shown name stays "Bridge". `lantern-post` is typed `lamp`, because `lantern` is a block, and
  `castle-gate` is typed `gate`.
- **The statue is a stone owl ("Stone Owl")** so that "You built a …!" reads well. "Owl Statue"
  would need "an".
- **Prices.** The cheapest plan is the lamp post (9 blocks) and the dearest is the tower (86).
  These are for the pedagogy and balance review.
