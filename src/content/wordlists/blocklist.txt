# SAFETY FILTER. This file is a blocklist, not content. It never ships to players.
#
# tools/validate-wordlists.ts checks every word list against it, in `npm test` and in CI.
# It is plain text on purpose, so anyone can read it and add to it. It lists words that must
# never reach children aged 6-13 through the game's word lists: profanity, slurs, sexual terms,
# violence and weapons beyond cartoon level, scary or sensitive topics, drugs and alcohol, unkind
# words, slang, brand names, and the IP terms of docs/impl/README.md section 4.5.
# Some lines below are offensive words. They are here only so the filter can catch them.
#
# When unsure, add the word. A false alarm costs an author a minute. A miss reaches a child.
#
# Format (README.md in this folder has more):
#   # section: <category>          the terms below match whole words only: "ass" blocks "ass",
#                                  not "glass"
#   # section: <category> strict   the terms below also match inside other words: "shit" blocks
#                                  "shitty". Only for terms that are never part of a harmless
#                                  word (check that "stab" is not hiding in "stable" first)
#   # section: allow               inflections that are not blocked as derived forms: last section
#   one term per line, lowercase a-z; a term with spaces matches those words in a row
#
# Every term also blocks its common forms, so list only the base word: "shoot" blocks "shoots",
# "shooting", "shooter"; "stab" blocks "stabbed", "stabbing"; "gun" blocks "gunman". The
# validator also undoes look-alike spellings ("k1ll", "sh-it") before matching. A category may
# have several sections, and the strict default stays: everyday words such as "kiss", "hit" or
# "ghost" are blocked on purpose until the owner's content read-through (M6-08).
#
# The validator reports the "ip" and "brands" categories as "trademark/IP term".
